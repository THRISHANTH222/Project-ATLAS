## 4. Multi-Tenant Vector Isolation & Cascade Deletion

### A. Multi-Tenant Isolation
- All query operations in `KnowledgeRetrievalService` filter vector search candidates by `companyId == current_user.company_id`.
- Users from `comp-alpha` cannot retrieve or access vector embeddings belonging to `comp-beta`.

### B. Cascade Deletion (Zero Orphan Guarantee)
When a document is deleted via `DELETE /documents/{id}`, `documents.py` executes:
```python
doc_chunks = await db.query_documents("chunks", "documentId", "==", document_id)
for chunk_record in doc_chunks:
    await db.delete_document("chunks", chunk_record["chunkId"])
```
This guarantees that deleting a document purges 100% of its vector embeddings from Firestore, ensuring **zero orphan chunks** remain.
